# 图书借阅管理系统 — 前端工程分析设计报告

> 版本：Release 1.0.0　　生成日期：2026-09-07　　技术栈：Vue3 + TS + Vite + Pinia + Vue Router + Element Plus

---

## 一、项目概述

本项目为「简易 PC 端图书借阅管理系统」的前端工程实现，基于 `PRD.md` 与 `prototypes/` 原型产物落地为可独立运行、可测试的 Vue3 单页应用（SPA）。前端采用纯前端模拟数据（localStorage 持久化 + 内存业务逻辑），无需真实后端即可完整体验登录注册、图书管理、借阅归还、收藏、个人资料等全部功能。

### 1.1 项目目标

- 将 PRD 中描述的图书馆藏管理与借还流程线上化，覆盖管理员与读者两类角色。
- 提供可即时运行、可交互测试的前端原型工程，便于演示与评审。
- 沉淀一套结构清晰、可平滑切换至真实后端的工程骨架。

### 1.2 范围

- ✅ PC Web 端（最小支持 1280×720，不做移动端适配）。
- ✅ 登录/注册、角色权限隔离、图书 CRUD、分类管理、借阅记录、办理归还、图书浏览/详情、借书/还书、收藏、个人资料、修改密码、退出登录。
- ❌ 罚金计算、消息推送、移动端适配、采购盘点等（与 PRD 范围外项一致）。

## 三、核心模块设计

### 3.1 数据层（mock/db.ts）

- **存储介质**：浏览器 `localStorage`，键名与原型保持一致（`lib_users`/`lib_cats`/`lib_books`/`lib_records`/`lib_favs`/`lib_seq`）。
- **种子数据**：首次加载自动初始化——管理员 `admin/123456`，读者 `reader1/123456`（张三）、`reader2/123456`（李四）；4 个分类；7 本图书；2 条借阅记录（其中 1 条为逾期，借出时间设为 40 天前）。
- **工具函数**：`now()`、`addDays()`、`isOverdue()`（实时判定 BR-07）、`paginate()`、`nextId()`。
- **业务常量**：`LOAN_DAYS = 30`、`BORROW_LIMIT = 5`（参数可配置）。

### 3.2 接口层（api/*）

每个模块函数返回 `Promise`，内部经 `mockRequest` 模拟 ~120ms 网络延迟后执行业务逻辑，统一以 `BizError` 抛出业务异常，由视图层 `ElMessage.error` 捕获提示。

| 模块 | 主要函数 |
| --- | --- |
| auth.ts | login / register / getProfile / updateProfile / changePassword / logout |
| book.ts | listBooks / getBook / createBook / updateBook / deleteBook / uploadCover |
| category.ts | listCategories / allCategories / createCategory / updateCategory / deleteCategory |
| borrow.ts | listAllRecords / listMyRecords / borrowBook / returnBook |
| favorite.ts | listMyFavorites / isFavorited / toggleFavorite |

> **后端切换路径**：将各 api/*.ts 中 `mockRequest` 调用替换为 `request.ts` 内 axios 实例请求即可，类型与函数签名保持不变。

### 3.3 状态层（stores/*）

- `useUserStore`：持有 `user`/`token`/`role`，提供 `init/login/register/updateProfile/changePassword/logout`，`role` 为 `computed` 供路由守卫与 UI 判断。
- `useCategoryStore`：缓存分类列表供下拉选择与筛选复用，`nameOf(id)` 解析分类名。

### 3.4 路由与权限（router/index.ts）

- **路由表**：公共 `/login`、`/register`；管理员 `/admin/*`（含 books/categories/records/profile）；读者 `/reader/*`（含 books、books/:id、borrows、favorites、profile）。
- **守卫**：
  - 未登录访问受保护页 → 跳 `/login`；
  - 已登录访问登录/注册 → 跳对应角色首页；
  - 角色不匹配（读者访问管理员页或反之）→ `ElMessage.error('无权限访问')` + 跳回本角色首页；
  - 首次进入若有 token 自动 `init()` 恢复用户态。

### 3.5 布局组件

- `AdminLayout` / `ReaderLayout`：固定左侧栏（深色 `#001529`）+ 顶部用户栏（60px）+ 内容区；顶栏右侧下拉头像菜单含「个人资料」「退出登录」；退出二次确认后清态跳登录。
- `BookCover`：通用封面组件，有 `cover_url` 显示图片（`@error` 回退），无则按书名 hash 取稳定色块 + 首字。

## 五、业务规则实现映射

| 规则 | 实现位置 | 说明 |
| --- | --- | --- |
| BR-01 借阅上限 5 册 | borrow.ts `borrowBook` | 统计本人 `status!==returned` 记录数，≥5 拒绝 |
| BR-02 借期 30 天 | borrow.ts `borrowBook` + db.ts `LOAN_DAYS` | `due_time = now + 30d` |
| BR-03 可借为 0 禁借 | borrow.ts `borrowBook` + 视图按钮 disabled | 提示「该书已借完」 |
| BR-04 逾期禁借 | borrow.ts `borrowBook` | 本人存在 overdue 即拒绝 |
| BR-05 有借阅记录禁删图书 | book.ts `deleteBook` | 统计 active 记录，>0 抛「尚有 N 册未归还」 |
| BR-06 一记录一借出 | borrow.ts `borrowBook` | 每次借阅生成新记录 |
| BR-07 逾期实时判定 | db.ts `isOverdue` + `refreshStatus` | 查询时刷新 status |
| BR-08 编辑馆藏联动 | book.ts `updateBook` | `newTotal < borrowed` 拒绝；`available += (newTotal - oldTotal)` |
| BR-09 记录不可删 | — | 无删除接口，仅归还 |
| BR-10 逾期不拦还书 | borrow.ts `returnBook` | 仅借书校验逾期，还书不拦 |
| BR-11 非空分类禁删 | category.ts `deleteCategory` | `book_count>0` 抛「有 N 本图书」 |
| BR-12 封面 jpg/png ≤2MB | book.ts `uploadCover` | 前置校验类型与大小，返回 dataURL |
| BR-13 收藏切换 | favorite.ts `toggleFavorite` | 存在则删、不存在则加 |
| BR-14 删图书级联删收藏 | book.ts `deleteBook` | 删除图书时清理对应 favs |
| BR-15 用户名/姓名只读 | Profile.vue | 输入框 `disabled` |
| BR-16 手机/邮箱格式 | auth.ts `register/updateProfile` + 表单 rules | 11 位、含 @ |
| BR-17 退出清态防后退 | user.ts `logout` + 路由守卫 | 清 token/user，跳登录，受保护页拦截 |
| BR-18 改密验原密码 | auth.ts `changePassword` | 不匹配抛「原密码不正确」 |
| BR-19 新密 6-20 + 一致 | auth.ts `changePassword` + 表单 rules | 长度与两次一致校验 |
| BR-20 改密成功重新登录 | Profile.vue `onChangePwd` | 成功后清态跳登录 |

## 八、关键设计决策与权衡

1. **纯前端 mock 而非 Mock Service Worker**：业务逻辑直接写在 `mock/db.ts` + `api/*.ts`，类型一致、调试链路短；切换真实后端仅需替换 api 内部实现。
2. **localStorage 持久化**：刷新页面数据不丢，借还状态在管理员与读者端双向可见，贴合 PRD「数据一致性」要求。
3. **共享 Profile 组件 + 双布局**：个人资料页逻辑完全一致，仅菜单与顶栏随布局变化，避免重复代码。
4. **封面 dataURL 预览**：原型阶段用 `FileReader` 转 dataURL 存入 `cover_url`，无需服务器，与 PRD「上传后存为可访问 URL」语义对齐；真实部署替换为上传接口即可。
5. **逾期实时判定**：查询时 `refreshStatus` 刷新 `status`，无需定时任务，符合 BR-07。
6. **路由级角色隔离**：前端守卫拦截 + UI 隐藏双重保险，PRD 要求「后端同步鉴权」在后端接入后于 `request.ts` 拦截 401/403 即可对齐。

## 九、后续优化建议

- 主包体积优化：Element Plus 改为 `unplugin-vue-components` 按需引入（已配置 resolver，可进一步 tree-shake）。
- 封面上传接真实后端时，删除图书不清理磁盘旧文件（BR-12），需后端策略兜底。
- 借阅上限/借期参数化：抽取为配置文件或后端接口下发。
- 引入 ESLint + Prettier 统一代码风格。
- 真实后端联调：将 `api/*.ts` 内 `mockRequest` 替换为 axios，并在 `request.ts` 增加 401 自动跳登录、403 提示无权限。
